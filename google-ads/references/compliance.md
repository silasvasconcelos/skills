# Compliance e segmentos

## Triagem de informação

| Classe | Uso |
|---|---|
| **Confirmado** | Usuário ou fonte confiável (site oficial, materiais do negócio) |
| **Hipótese** | Possibilidade não verificada — nunca em anúncio como fato |
| **Recomendação** | Sugestão de experiência — rotular como sugestão |

Fluxo quando dado ausente: fontes do usuário → site oficial → materiais → ferramentas → perguntar. Ainda ausente → não usar.

## Canais de contato (negócios locais)

Perguntar por quais meios clientes devem entrar em contato. Coletar dados completos por canal:

| Canal | Dados |
|---|---|
| WhatsApp | Número + DDD, link direto, mensagem inicial |
| Telefone | Número, horário atendimento |
| Site / formulário / agendamento | URL |
| Instagram | Perfil |
| Endereço | Unidade que recebe clientes |

Recomendar canal de menor atrito; usuário prioriza.

## Clínicas de estética — políticas

Antes de publicar, verificar políticas atuais sobre: saúde, aparência, características pessoais, antes/depois, promessas de resultado, emagrecimento, gordura localizada, pele, procedimentos estéticos, segmentação personalizada, remarketing, afirmações médicas, conteúdo sensível.

Risco identificado → explicar e oferecer alternativa segura. Nunca burlar políticas.

## Recomendações automáticas do Google

Classificar: recomendada, opcional, não recomendada, necessita teste. Interesse do negócio > pontuação de otimização da plataforma.

## Confirmação obrigatória

Antes de executar: publicar campanha nova, aumentar orçamento, remover campanha/grupo/anúncio/conversão, remover muitas palavras-chave, pausar conta/campanha relevante, mudança significativa de lance ou geografia, qualquer ação irreversível ou alto impacto financeiro.

Formato: **o quê → impacto → valor → riscos → confirmação**.

## Teto como restrição rígida

Orçamento informado = **limite máximo autorizado**. Se estratégia precisar mais: quanto recomendado, por quê, benefício possível — manter teto atual até autorização.
